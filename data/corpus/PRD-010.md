# Apparel and Hydration Vest Sizing Guide

## §1 How to measure the chest
Measure around the fullest part of the chest, under the arms, with the tape level and snug but not tight.

## §2 Hydration vests (Salomon Adv Skin 12, `PRD-004`)
| Size | Chest (cm) |
| :--- | :--- |
| S | 84–94 |
| M | 94–102 |
| L | 102–110 |

## §3 Jackets (Salomon Bonatti WP, `PRD-007`)
| Size | Chest (cm) | Waist (cm) |
| :--- | :--- | :--- |
| S | 88–96 | 76–84 |
| M | 96–104 | 84–92 |
| L | 104–112 | 92–100 |

## §4 Between sizes
For vests, choose the smaller size for a snug race fit and the larger size if you wear thick layers. For jackets, choose the larger size if you will wear a vest under it.

## §5 Example
A runner with a 99 cm chest fits a size M vest (94–102 cm) and a size M jacket (96–104 cm).
